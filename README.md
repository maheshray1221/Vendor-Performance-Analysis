## 📌 Overview

> This project focuses on analyzing vendor performance based on sales data.

It involves **data ingestion**, **cleaning**, **exploratory data analysis (EDA)**, **automation of summary generation**, and **dashboard development using Power BI**. The project concludes with a comprehensive report containing **actionable insights**.

## 🚀 How to Run

<details>
<summary><b>Step-by-step guide (click to expand)</b></summary>

<br>

1. **Clone the repository**
   ```bash
   git clone https://github.com/maheshray1221/Vendor-Performance-Analysis.git
   ```
2. **Open Jupyter Notebook** and run the EDA and analysis notebooks in `/notebooks`
3. **Generate the vendor summary** using
   ```bash
   python scripts/get_vendor_summary.py
   ```
4. **Open the `.pbix` file** in Power BI for the dashboard view
5. **Review the final report** in `/reports`

</details>
